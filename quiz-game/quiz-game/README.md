# 🧠 Quiz Game

An interactive Python quiz game created as part of my programming journey and GKS portfolio.

## Features

- 10 questions
- Randomized question order
- Multiple-choice answers
- Automatic scoring
- Percentage calculation
- Performance feedback
- Input validation
- Option to replay

## Topics Covered

The quiz includes questions about:

- Mathematics
- Biology
- Chemistry
- Computer Science
- Web development
- Ghana
- Korean language

## Skills Demonstrated

- Python functions
- Lists
- Dictionaries
- Loops
- Conditional statements
- Randomization
- Input validation
- Score calculation

## What I Learned

This project helped me practice storing structured information using dictionaries and lists while combining them with functions, loops, conditional logic, and user input.
