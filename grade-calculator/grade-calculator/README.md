# 📊 Grade Calculator

A Python program that calculates students' overall academic performance from their subject scores.

## Features

- Accepts scores from 0-100
- Calculates the overall average
- Assigns grades
- Provides performance remarks
- Validates incorrect scores
- Supports multiple subjects
